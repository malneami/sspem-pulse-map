# خريطة النبض | Pulse Map

حملة **الجمعية السعودية لطب طوارئ الأطفال** — «نبض واحد.. لأطفال الوطن».

هذا المستودع يحمل **الخريطة العامة والمحتوى المعتمد فقط**، بصيغ مفتوحة يسهل نقلها لموقع الجمعية لاحقاً بنسخ المستودع كما هو.

## البنية

| المسار | المحتوى |
| --- | --- |
| `index.html` | الخريطة العامة (GitHub Pages) |
| `data/regions.json` | المناطق الـ 13 وإحداثياتها |
| `data/entries.json` | المشاركات المعتمدة: المستشفى (بالاسم المصحّح)، المنطقة، النصيحة بأجزائها، الموقع، تاريخ النشر |
| `media/<id>/` | ملفات كل مشاركة معتمدة: `video.mp4`، `speaker.jpg`، `ed1.jpg`…، `facade.jpg` |

## ما لا يدخل هذا المستودع أبداً

أرقام الجوال، بيانات التواصل، الإقرارات، والمشاركات غير المعتمدة أو المرفوضة. هذه تبقى في المخزن الخاص لنموذج المشاركة وتُحذف حسب سياسة الحملة.

الإضافة إلى هذا المستودع تتم آلياً عند اعتماد المشاركة من لوحة المراجعة.
